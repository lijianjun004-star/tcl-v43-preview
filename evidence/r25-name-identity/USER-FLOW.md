# 姓名登录使用说明

TCL 练播房｜姓名登录说明（2026-11-17）

1. 先发邀请码
原管理员选择“姓名和密码登录”，填写“运营管理员”和原密码，进入云端工作台的“邀请成员”。选择“运营”或“主播”，点击“生成一次性邀请码”，分别发给对应本人，每人一个。
管理员可邀请运营和主播；运营只可邀请主播；主播没有邀请入口。邀请码自动决定角色，使用者不用自行选角色。

2. 第一次加入
选择“首次使用邀请码加入”，填写自己的姓名、自己设置的密码和收到的邀请码，点击“加入练播房”。运营和主播都这样加入，不用另外申请独立账号，也不用手机、邮箱或验证码。
密码8–32位，首位用字母或数字，建议同时包含大小写字母和数字。姓名可用中文或其他文字；请记住自己填写的完整姓名。

3. 以后登录
选择“姓名和密码登录”，填写加入时的姓名和密码即可。换手机或浏览器也用这两个信息，不用重复填邀请码。原用户直接用原身份和原密码登录，不必重新加入。

4. 重名与断网
同名同事可在姓名后加部门或编号，以后登录也填写这个完整姓名。已有自己的身份时请直接登录，不要通过重注册认领旧记录；姓名相同不会自动合并数据。
首次加入遇到断网，请在同一浏览器用相同姓名、邀请码和首次设置的密码再次点击，继续原操作，不要反复更换姓名或密码。

5. 两种口令别混用
“加入邀请码”：首次建立登录身份，决定你是运营还是主播，一次性使用。
“作业口令”：登录后加入某一份训练作业，在主播首页“输入运营给你的作业口令”处填写，不能拿来登录或首次加入。

6. 原记录继续保留
原身份（UID）及其已有云端记录保留；姓名登录不会换成另一个身份。只有已提交并获云端回执的内容，才能在其他设备查看。
未上传的文字和录音录像仍在原设备、原浏览器，不会按姓名自动迁移。可在云端工作台展开“旧本机体验记录”，点“只读导出旧本机文字（不上传）”下载文字备份；这不会删除、上传或归属当前身份，也不包含录音录像。请继续保留原浏览器及媒体原文件。
