# 显式产品字段与导入身份回归

产品模块：`lib/qa-import.js`，最终 SHA-256 `fac35e52b9a5effd3642919cc0ce6f60dc744b166639ebe8564b67841ad1ff86`。

`metadata.json`：实际 Chromium 读取人工构造的 CSV、完整 XLSX、完整 DOCX 和 JSON；4种格式都保留两条不同型号的同题记录及各自答案。另执行67项身份、范围交集、来源、别名、类型和容量验证。测试前后模块哈希相同。相邻 `../import-regression/import-mappings-after.json` 记录之前24项数据映射回归再次通过。

输出字段：`model`、`sku`、`category`、`platform`、`sourceRef` 始终为字符串，缺失为空；`sourceLocators` 为全部行来源字符串数组，旧 `locator` 保留首来源。SKU独立于型号；不从回答或文件名猜产品字段。运营表仅在问题、型号、SKU、品类、平台相同的身份内合并多话术，并保留各行位置与来源原文。

去重和冲突分开：严格同身份同答案标记重复；相同问题/型号/SKU且适用范围有交集，答案不同时标记冲突。支持全部平台、京东/天猫组合及同品类共享范围；互斥平台、不同产品身份不混合。范围不同但答案相同可继续审核，以免错误丢失新增覆盖范围。

容量：型号/SKU各200字，品类100字，平台50字，来源引用2000字；来源位置最多1000项、每项1000字。超限明确报错，不截断。元数据允许文字及有限数字；布尔/对象/数组不作为型号等字段。超出JavaScript安全整数范围的数值必须在源资料中改为字符串。来源引用大小写敏感，显式`sourceRef`优先旧`source`展示标签；空白显式来源不屏蔽有效来源别名。

`scope-metadata-before.json` 是修改前实际Node运行的失败输入和输出，记录范围交集漏冲突、大整数SKU舍入、来源路径大小写误合与空白来源遮挡。不是根据新代码推演的历史结果。

全部为人工构造资料，不证明真实TCL型号参数已核准。此次只修指定元数据与身份逻辑；旧Q/A多别名字段同时含不同值的解释规则未扩展。未自动发布，没有Gemini调用。
