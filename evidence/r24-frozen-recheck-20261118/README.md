## 原版功能实测

| 测试 | 结果 |
| --- | --- |
| 主播／运营姓名进入，模型选择 | PASS。两类角色均使用姓名进入，原页面没有密码或邀请码输入。Base 默认、Tiny 可切换，选项刷新后保留。 |
| 三题练播到复盘，Chromium 19 项 | PASS。隔离浏览器用虚拟麦克风和摄像头，实际 MediaRecorder 保存整场视频和三题音频。模拟转写按题绑定，晚到的结果保留人工编辑。结束直播后显示三题复盘及对应音频控件。 |
| 本机数据恢复，另跑历史 10 项 | PASS。复盘保存后刷新，四个 IndexedDB 媒体对象 SHA-256 和逐题文字快照恢复。还测到配额失败保留旧检查点、显式重试和中断恢复。 |
| 实际媒体回放补测，Chromium 21 项 | PASS。刷新前后各三段逐题录音和一段整场录像均执行原生播放。各段播放位置推进约 0.38 秒，两次视频播放各解码 9 帧，无媒体错误。视频容器未报告有限的总时长。 |
| 题库和来源信息 | PASS。CSV、XLSX、DOCX、JSON 四种格式和 67 项身份／元数据检查通过；24 个解析用例及既有型号区分通过，另有题库浏览器 32 项通过。验证型号、SKU、来源和定位信息。冻结版提供来源信息及随附组件许可文件，逐文档版权授权字段未实装。 |
| 窄屏，Chromium 90 项 | PASS。320、390、430 px 下验证输入 16 px、页面缩放比例 1、长链接和 60 题分页与音频节点保留。 |
| 下载失败与恢复 | PASS。真实 Worker 加模拟模型的 5 个边界用例通过。页面在模拟初次下载失败时保留音频、允许手写，无虚构转写。另用原 bridge 阻断模型主源和镜像，返回错误且释放忙状态，网络恢复后同一实例完成真实 Tiny 推理。 |
| 历史发布门禁 | PASS。92 项单元测试。 |

## 交付与回滚

回滚 ZIP 是原版安装包的逐字节副本。Drive 回读后再次核对了 SHA-256、大小、CRC 和文件内容。需要恢复时，经用户确认，使用独立 PR 恢复 R24 的 `experiments/r24-release/site-only.zip.b64`，核对现有发布门禁和其他路由，再由 Pages 发布。R24 当前已是该基线。

本轮 PR 只记录复验结果，保持草稿。无产品改动、正式发布、CloudBase 写入或用户历史数据操作。
