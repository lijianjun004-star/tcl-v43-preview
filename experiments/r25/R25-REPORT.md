## 1. 改了什么

以 R24（app.js `63519c50…`）为基线，由 `tools/patch_r25.py` 机械生成。只改了 7 个文件，完整差异见 `R24-to-R25.diff`：

| 文件 | 改动 |
|---|---|
| app.js | 默认引擎改为 Vosk；每题录音结束后按引擎分流（`r25RouteAsr`）；Whisper 失败后自动下载 Vosk，并补转所有还没文字的题；开播前页面自动开始下载 Vosk（带进度条，出错后不会自动反复重试）；Vosk 模式下文案改为“中文识别模型”；命名空间改为 r25 |
| whisper-bridge.mjs | 加载或推理超时后终止 Worker 并清空状态，`isResourceBusy` 不再因此锁住 Vosk；本页的 Whisper 仍保持禁用 |
| asr-normalize.mjs | OpenCC 预设 `tw` → `twp`（支援→支持、软体→软件、萤幕→屏幕） |
| index.html / r23-model-choice.js | 引擎选择增加“本机中文识别 Vosk · 推荐手机”并设为默认；Whisper Tiny/Base 标为实验；标题改为 R2.5 |
| glossary-ui.mjs | 私有术语表的存储键改为 r25 |
| static-manifest.json | 版本 `r25-asr-fallback-20261116`，文件哈希全部重新计算 |

Whisper 是否停用整页的规则：只有加载、网络、超时、Worker 这类引擎级故障，才会让本页后续题目直接走 Vosk。如果只是某一题的音频解码失败或录音过长，只有这一题改用 Vosk，后面的题仍先走 Whisper。

### 2.3 真实 Vosk 模型的端到端流程（REAL 模型 + 合成普通话）

测试条件：
- 用真实的 Vosk small-cn 模型（12 个文件，按线上同一 URL 在本机提供），走 Chromium 真实的录音和解码。
- 麦克风输入是 espeak-ng 合成的普通话，**不是真人**。
- 外部域名全部在本机拦截：`abort` 让请求直接失败，`hang` 让请求挂起不响应。加载超时调成 6 秒，线上默认是 45 秒。

| 场景 | R24 | R2.5 |
|---|---|---|
| 默认设置，首次使用 | 走 Whisper，模型站点不可达时回答栏为空 | 开播前自动下载 Vosk，录音后约 8 秒写入本题回答栏，**0 个外部请求** |
| 选 Whisper Base，运行库加载直接失败 | 回答栏为空，提示“可手动填写” | 自动切到 Vosk，写入回答栏 |
| 选 Whisper Base，运行库加载挂起超时 | 回答栏为空，提示“资源被锁定，请重开页面” | 终止 Worker，自动切到 Vosk，写入回答栏 |
| 挂起超时，且 Vosk 已提前下好 | **仍然为空**，「补转写」也无效 | 立即由 Vosk 接手，写入回答栏 |
| 连续 3 题，每题分别录音 | — | 见 2.4 |

所有写入的文字都是简体，页面没有报错。

**准确率不能从这里推断**：合成语音很机械，Vosk 的识别结果大多是错字，例如“我们来”能识别出来，但整句基本不对。这一组测试只证明“录音 → 模型 → 本题回答栏 → 保存 → 复盘”这条链路是通的。

### 2.4 连续 3 题
默认 Vosk 模式下连续录 3 题，第 3 题只录了约 2.5 秒。结果：3 题都有文字，内容各不相同（对应循环播放音频的不同片段），各自写在自己的回答栏里，没有串题，0 个外部请求，页面没有报错。

## 4. 已知限制和取舍

- 第一次进入开播前页面会自动下载约 42MB。页面上有进度条，下载过程中可以继续操作；用手机流量的用户需要知道这一点。可以考虑在设置里加一个“仅 Wi-Fi 自动下载”的开关（交给 Codex 评估）。
- R2.5 的 Vosk 缓存和 R24 是分开的，所以从 R24 换过来要重新下载一次 42MB。
- 默认的 Vosk 准确率可能不如 Whisper Base。但 Vosk 在手机和国内网络环境下最可靠，而且直接输出简体。用户可以在首页手动切换到 Whisper，失败了也会自动回到 Vosk。

## 5. iPhone 真机验收步骤（每轮不超过 3 题）

1. 用 Safari 打开测试地址（部署后由 Codex 提供），以主播身份登录，进入自由练播。
2. 在开播前页面确认进度条出现，并记录下载完成用了多久。
3. 开播，每题说一句含型号或数字的话，例如“这款 T7M Pro 七十五寸支持 HDMI 2.1”，然后点下一条。一共说 3 题。
4. 结束直播 → 进入复盘 → 逐题复盘：检查每题回答栏有没有文字、文字是不是简体、有没有串题。
5. 点诊断导出，把 JSON 文件发给开发；**不要上传真人录音**。
6. 刷新页面，确认已保存的文字还在。
7. 在首页把引擎切到 Whisper Base，重复第 3–4 步，记录 Whisper 是成功了还是自动切到了 Vosk。
