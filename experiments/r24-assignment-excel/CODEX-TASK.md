# Codex 执行任务｜R24 Paraformer pages3 的 Excel 作业专属发布

请先读 `00-先读我.md` 和本任务书，然后从 GitHub **实时 main** 读取 `AI_CONTEXT.md`、Pages 工作流、PR #158 的最后正式静态包及可信门禁。用户已确认：Excel 一行一题，运营把它当作**专属作业**分给指定主播，不是上传公共知识库。

## 红线

- **严禁调整原 R24 pages3 的 UI 美术、布局、视觉比例、现有按钮和文案**，仅在原「① 发布作业」卡片中最小增量接入「上传 Excel、指定主播、预览、确认发布」操作。
- 必须保持原本姓名进入、Paraformer 模型、摄像头、录音、转写、结束、复盘和本机历史记录不变。
- 不能导入未经运营审核的 TCL 商业参数到公共题库；不能凭空补型号或标准答案。
- **禁止**把用户私有 Excel 原文写入仓库或公开 Pages。测试只用随包虚构样例。
- 原站、R25 和腾讯云现有静态入口全部保留；只用独立分支/PR和新的**隔离测试 URL**，不覆盖正式入口。
- 没有真正的跨设备后端就不能提示「已送达主播手机」；先使用本包手动 JSON 交换的明确过渡流程。涉及真实跨设备服务端身份与权限必须另立验收任务。

## 推荐步骤

1. 从主仓库导出 `experiments/r24-paraformer-release/site-only.zip` 的真实压缩内容并按 R24 pages3 SHA 校验。正式 app.js SHA 应为 `37eb6128081571861c712c9c1e5d07c75fb498d08091e8f2ee94a48c00ef19ec`；若仓库较新以当前发布清单为准，先比较差异。
2. 查看 `implementation/tools/apply_to_r24.py`；该脚本以历史 R24 为精确基线，**不能强制替换不匹配的 pages3**。如锚点有变化，只移植对应的独立作业逻辑，在当前真实 pages3 修改，保持最小 diff。必须保留 Paraformer worker/bridge 与原始模型资源。
3. 新增纯函数 `assignment-excel.mjs`，复用 `parseDocumentFile`/`extractQA`，并将 XLSX 命名空间兼容修复最小移植到 `lib/parser.js`。在 `lib/qa-import.js` 识别 Excel `题目/作业题目` 表头。
4. Excel 表格从浏览器本机读取，验证题目、参考答案、型号、SKU、评分点、品类、平台；缺列、重复题、非法型号/敏感信息、错平台一律拒绝整批保存。**先预览并由运营确认后才能创建专属作业快照**。
5. 锁定作业 ID、版本、内容哈希及接收主播名单。修改后必须新建作业版本，不得修改已训练作业的题目与历史提交。`getEntries()`/公共知识库保持原逻辑；作业入场从冻结 `assignment.questions` 生成固定题池，按 Excel 行顺序只练一次。提交必须确认每道题有回答和作业版本匹配。
6. 运营进度页列出被分配主播（包括未加入）与真实本机状态。跨设备只能用**运营导出 JSON 作业包→主播导入→完成后导出 JSON 回执→运营导入**；不宣称身份已认证、任务自动推送或数据已经云同步。后续如要自动跨设备，需要后端授权与客户端绑定/审计。
7. 运行 `node --test implementation/tests/*.test.mjs`（24 项当前通过），再跑真正的 Excel 文件和手机尺寸 Chromium E2E，至少覆盖 Excel 3 题、错平台、重复题、未选收件人、发布后源表修改、另一个主播不可见、三题录音转写、每题来源/答案、结束提交、JSON 导出和恢复、公共题库零变化。
8. 仅在新命名空间 `/tcl-r24-paraformer-excel-qa/` 做测试部署，并将 IndexedDB、BroadcastChannel、缓存键与正式 pages3 完全隔离。遵循原项目可信 CI；任何安全失败停止。不直接修改 CloudBase 正式静态托管。
9. 完成后输出：源码 ZIP、完整 manifest + SHA256SUMS、PR / commit SHA、Actions 真实状态、逐题 E2E 结果和截图、原 CSS/HTML/Paraformer 资源 diff=0、回滚指导。需要用户验收 UI 与数据隔离后再决定正式升级。

## 验收标准

Excel 一行一题且题目完整；运营能预览、指定主播、保存专属作业；主播只收到分配给该姓名的任务；不能从公共题库混题；重复切题不自动无限循环；未完成不能提交成已完成；提交回执带有唯一作业版本/题目摘要；原系统功能无回退。任何尚未执行的真机测试必须标 **NOT RUN**，不能写 PASS。
