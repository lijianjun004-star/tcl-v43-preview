# R24 离线电视作业草稿

工作流 R24 offline TV question workbook 使用仓库已有的 Actions secret，在一次模型请求中为固定的合成电视选购案例生成 5 道题。运营从 Actions 运行页面下载 R24-offline-TV-review。附件保留 3 天。重跑这项工作会再次调用模型并产生用量。仓库的运行日志仅记录模型、题数和实际 token 计数。这个示例分支只处理可公开的合成教学内容。

运营可在上海试点工作台的「发布作业」选择电视板块及京东平台，上传 R24-TV-review.xlsx 并点击「解析并预览作业题目」。如需编辑，也可复制 questions.json 的完整内容到「AI 出题草稿」的模型回复框，解析、逐题修改并确认。参考话术涉及价格、型号和安装服务的部分须与对应官方商品页及订单条款核对。运营最后点击发布才会创建可供主播领取的作业。

usage.json 保存本次运行的模型快照和用量。工作流不登录上海业务系统。正式案例及内部运营资料不应提交到这个公开示例分支。
