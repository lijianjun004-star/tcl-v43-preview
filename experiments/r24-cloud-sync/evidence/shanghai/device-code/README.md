# 上海 R24 试点自助设备码

2026-11-24 已部署 `r24-paraformer-excel-cloud-sync-device-code-20261124`。工作台「换手机 · 生成设备码」可复制或下载个人备用码。首次开通仍由管理员发码。每枚码有效 90 天并限用一次。发新码只撤销同一身份先前未使用的自助码，已有设备和管理员签发的码保留。

- 公网实测两个独立 Chromium 浏览器。原设备已绑定，生成备用码，另一浏览器填写同一姓名并使用该码绑定。两边的身份和作业列表完全相同，无页面异常。只生成一枚自助码，无作业写入。
- 本地浏览器 4 项通过，包括生成、复制、下载、换码及拒绝旧码。18 项后端测试通过。PostgreSQL 仅授予服务角色签发函数执行权限，公网未绑定请求得到 401。
- 只更新现有试点的 4 个前端文件、对应试点函数以及独立试点设备表及签发函数。公网 37/37 哈希匹配，原 QA3 清单一致。设备码原文和设备凭据未进入报告和源码。
