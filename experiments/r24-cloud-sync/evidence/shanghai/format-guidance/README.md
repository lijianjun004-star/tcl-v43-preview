# 设备码提示与云同步状态验收

2026-11-24，上海 R24 试点已发布 `R24-20261124.1` 完整版本 `r24-paraformer-excel-cloud-sync-code-format-20261124.1`。

- P1 格式提示明确 `R24-` 前缀、总计 28 个字符、后 24 个字符为十六进制，并指向本试点的已绑定设备。绑定页可见示例。
- P1 粘贴容错清理空白、换行与常用不可见空白，兼容全角字符和常见连字符。客户端仍要求原有 R24 码格式，发给绑定接口的是原规范形式。16 位无前缀码仍会在本机被拒绝。
- P2 云试点显示「未绑定设备」、「待登录」或服务端确认后的「已绑定」。登录卡片及生成器显示一致的短版本。避免旧本机文案在登录后重复覆盖状态。
- 本地 Chromium 回归 6/6。公网用合成主播的两个独立浏览器验证提示、签发、带格式变化的粘贴和成功绑定，两端看到同一身份和作业列表。0 页面异常。公网资源 37/37，原 QA3 清单一致。
- P0 来源待定位。本次检查的 R24/R25 已知生成路径无 16 位大写无前缀码输出证据，用户表示原生成页地址找不到。再次出现时保留生成页地址栏及页面版本，设备码与姓名可遮盖。实体手机的原始问题尚未复验。
