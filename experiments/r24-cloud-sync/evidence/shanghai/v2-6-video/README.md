# R24 `.6` 长录像验证

2026-11-25 UTC，上海公网版本 `R24-20261124.6`，清单 SHA-256 `3ff8696ff1c7c7d33d2a0e9e0e01ea3197832e2c3f6f5e9b7c28c4fe114d0a9e`。公网版本与本机候选的清单及关键文件匹配。录像测试使用同一候选、独立 Chromium、合成摄像头及麦克风、本机测试后端。未新增公网账户、作业或录音。

| 验证项 | 结果 |
| --- | --- |
| 实际长录像，可播放和下载 | 两次实际连续录制，约 190 秒（9,820,677 字节）和 185 秒（9,560,295 字节）。均为 640×480 VP8 视频与 Opus 音频。第一段在网页中跳转到第 170 秒后继续播放，第二段播放与下载通过。 |
| 原浏览器刷新后恢复 | 185 秒场次已确认本机保存，刷新、恢复复盘后录像仍可加载。 |
| 长录像本机转写及导出 WAV | 185 秒场次在两入口均收到「最多 180 秒」提示，原视频仍可播放和下载。另有 48 MiB 的整场本机解码限制。 |
| 自动停止 | 设置 6 秒测试阈值后，约 6.4 秒进入复盘，下载文件两轨均约 6 秒并可播放。线上默认时间阈值为 8 分钟，或已收到录像分块累计达到 64 MiB 时提前停止。完整实录 8 分钟和 64 MiB 分块阈值未运行。 |
| 整场录像随作业传给运营 | 当前不支持。现有云端提交保存文字、转写和逐题录音，单段可上传音频最多 512 KiB。整场视频仅在原浏览器回放、保存和下载。`.6` 的三段逐题录音此前已实际通过公网传输和播放。 |

Chromium 试验生成的 WebM 无容器总时长字段。第一次断言读取不到容器总时长，使用 `ffprobe` 的音视频包尾时间确认两个轨道均到约 190 秒。第二次以包时间核验并通过。真机、微信、真实人声和长录时切后台未实测。
