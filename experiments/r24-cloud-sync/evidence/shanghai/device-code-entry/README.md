# 登录页设备码入口

上海 R24 试点 `r24-paraformer-excel-cloud-sync-device-code-entry-20261124` 已发布。登录页「进入」下方显示「生成设备码」。已绑定的浏览器填姓名后点击，服务端按原有绑定确认身份，然后打开工作台生成器。未绑定的浏览器显示取码指引及设备码输入框。点击入口本身不会生成码。

本地 Chromium 验收 5/5，包含已绑定直达、未绑定提示、既有生成与作业流程。390px 公网 Chromium 核实入口可见、未绑定指引可用、未发送激活和签发请求。公网资源 37/37，原 QA3 清单一致。本轮仅更新试点的三个前端文件。
