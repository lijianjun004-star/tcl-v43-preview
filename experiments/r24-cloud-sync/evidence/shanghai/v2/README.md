## 交付内容

- 主播及运营首次用姓名和所选角色开通。回访验证当前设备凭证，同名新设备沿用服务端已登记角色，重置只撤销设备绑定和可用设备码。旧账号 ID 与历史作业继续保留。
- 单次设备码为 `R24-` 加 24 个小写十六进制字符，30 分钟有效。生成器提供倒计时、姓名、角色、复制和下载。粘贴时清理空白、全角、零宽字符和常见破折号；绑定入口锁定并发提交。
- Excel 审核规则和冻结哈希由服务端验证。运营发布后，同一试点团队的主播可直接搜索、领取和提交。文字和已有转写先入库；符合限制的逐题录音后传到私有桶，单段最多 512 KiB。整场录像和未提交草稿留在原浏览器。
- 候选 `.2` 公网复测碰到首次模型加载期间已手填的作答不能立即提交。`.3` 在每题已有核对内容时允许明确确认，先提交现有文字、已生成的转写和录音，原录音保留。已在本地对模型下载加入延迟复测。`.4` 修复运营在「主播记录」加载期间搜索可能覆盖本次读取结果的问题。
- Gemini 的附件用于核对界面提示、换机流程和测试点。部署基于现有 PostgreSQL 试点、原身份 ID 和完整 QA3 模型资源，保留旧绑定、记录和草稿路径。
